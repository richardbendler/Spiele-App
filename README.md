# Trinkspielapp

Dies ist das Hauptverzeichnis der Trinkspielapp. Das Verzeichnis besteht aus den beiden Bestandteilen Backend und Trinkspiel_RN, die beide im Folgenden kurz erklärt werden.

## Backend
Das Backend läuft auf einem von Richard gemieteten Debian-Server und muss für das grundlegende Entwickeln an der App nicht angefasst werden.
Der Ordner Backend unterteilt sich noch einmal in js und rocket, wobei js eine alte Version des Backends ist, die mittlerweile eigentlich nicht mehr gebraucht wird. Der rocket-Server basiert auf RUST.
Weitere Infos zum Backend sind in der README im Unterordner zu finden.

## Trinkspiel_RN
Hier befindet sich die React Native App, die gebuilded werden kann um deployed zu werden. 
Weitere Infos sind in der README im Unterordner zu finden.
